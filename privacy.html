Privacy Policy

Last updated October 14, 2026.

Daily Brief is a personal, single-user tool. Its only user is its owner, who runs it on their own Mac.

What data it accesses

With the owner's permission, it reads the owner's own Gmail messages and Google Calendar events. It can set the owner's RSVP on a calendar invite or copy an event onto the owner's own calendar, only when the owner clicks a button to do so. It never sends, deletes, or modifies email.

How the data is used

The data is used only to produce the owner's own daily summary. Short excerpts are sent to Anthropic's Claude to write the summary, under the owner's own Claude account. Nothing is used for advertising, sold, or shared with anyone else, and no humans other than the owner read it.

Storage

Sign-in tokens are stored in the macOS Keychain on the owner's Mac. Generated summaries stay on that Mac. Nothing is stored on any server operated for this tool.

Google API Services

Daily Brief's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
